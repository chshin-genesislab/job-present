# AI 에이전트 개발자 · 직무 소개

DX School 특강 발표 자료 — HTML 슬라이드 24장.

## 배포
저장소 루트에 이 파일들을 올리고, Settings → Pages에서 `main` / `/ (root)`를 선택하면 됩니다.
기존에 올려둔 단일 `index.html`(번들)은 이 `index.html`로 덮어쓰면 됩니다.

## 구조
- `index.html` — 진입점 (React · Babel CDN)
- `styles.css` — 전체 스타일
- `app.jsx` — 셸 · 사이드바 · 슬라이드 목록
- `slides-*.jsx` — 슬라이드 정의
- `assets/agentria-icon.png` — 로고
